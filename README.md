# Window Controls

Corner buttons for Omarchy windows. Drag a window from the grip, resize it from the edges or the corner handle, and snap it by dropping it on a corner or a side. Minimize hides the window and leaves a button at the bottom-left that opens it again.

## Install

```bash
omarchy plugin add https://github.com/andersonmorillo/window-controls.git --enable
```

## Remove

```bash
omarchy plugin remove li.window-controls
```
